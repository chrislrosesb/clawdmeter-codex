Agent messages on Clawdmeter

How the 2.16-inch AMOLED looks when a Pluribus agent has a message waiting. Each screen is drawn at the panel's true 480 × 480 pixels, 1:1. Design mockup only; no firmware has changed.

Captions are sample data

Notes for whoever builds it

  • All names, times and captions are made-up sample data. Mila is the current name for the sales-marketing agent (formerly Scarlett).
  • Type sizes match fonts already in the firmware: Mono 18 for labels, Styrene 28 for the caption, Tiempos 34 for the bubble and count. Web fonts stand in here.
  • Tori's frames come from the Pluribus AgentRig art (champion heads: neutral, wink, talk). Other faces are the existing Pluribus avatar medallions.
  • Everything stays 32 px in from the edges to clear the panel's rounded corners.
